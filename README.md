# SmartDehqon

SmartDehqon — sun’iy intellekt asosida ishlovchi aqlli agroplatforma bo‘lib, o‘simlik rasmi, hudud va agro-ma’lumotlar asosida kasalliklarni erta aniqlaydi hamda hosildorlikni bashorat qiladi. Loyiha dehqon va fermerlarga tezkor tavsiyalar berib, hosil yo‘qotishlarini kamaytirish va resurslardan samarali foydalanishga yordam beradi.
